Politica de privacidad

Ultima actualizacion: 24/08/2026

Mi Porra Tu Gloria es una aplicacion privada para crear y participar en porras deportivas entre usuarios invitados.

Datos que podemos tratar

  • Nick o nombre de usuario.
  • Email, si el usuario lo facilita.
  • Contraseña de acceso a la aplicacion.
  • Avatar elegido por el usuario.
  • Pronosticos, resultados, clasificaciones, mensajes de chat y participacion en porras.
  • Datos tecnicos necesarios para el funcionamiento de la web/app, como datos de sesion guardados en el dispositivo.

Para que usamos los datos

  • Permitir el acceso de los usuarios a sus porras.
  • Guardar pronosticos, puntuaciones, clasificaciones y mensajes.
  • Gestionar porras privadas, premios, usuarios y opciones de administrador.
  • Mejorar la seguridad y evitar accesos no autorizados.

Servicios externos

La aplicacion usa Supabase para base de datos, autenticacion y almacenamiento de informacion de la app. Tambien puede usar servicios externos para sincronizar calendarios y resultados deportivos.

Con quien compartimos los datos

No vendemos datos personales. Los datos se usan para el funcionamiento de la app. Dentro de cada porra, otros participantes pueden ver informacion necesaria para jugar, como nick, pronosticos visibles segun las reglas de la porra, puntuaciones, mensajes y clasificaciones.

Seguridad

Aplicamos medidas razonables para proteger la informacion, incluyendo permisos de base de datos, controles de administrador y acceso limitado a la informacion necesaria.

Conservacion y eliminacion

Los datos se conservan mientras la cuenta o la porra sigan activas. El administrador puede gestionar usuarios y, cuando corresponda, eliminar o recuperar cuentas desde las opciones de administracion.
